## 🚀 DEPLOYMENT OPTIONS

### Option 1: Local Development
```bash
python -m uvicorn src.api.server:app --reload
open frontend/index.html
```

### Option 2: Docker Single Node
```bash
docker build -t dkvs:latest .
docker run -p 8000:8000 dkvs:latest
```

### Option 3: Docker Cluster
```bash
docker-compose up -d
# Starts 3-node cluster with load balancer
```

### Option 4: Kubernetes
```bash
kubectl apply -f k8s-deployment.yaml
# Production-grade Kubernetes cluster
```
